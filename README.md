# Gestionale Casa Rosa

Gestionale per il B&B (camere 5 e 6): prenotazioni, calendario, archivio ospiti, statistiche, costi e tassa di soggiorno.

App online: https://sassarolifederico-lab.github.io/Gestionale---Casa-rosa/

Si installa su telefono e computer dal browser (Android: menu ⋮ → Installa app; iPhone: Condividi → Aggiungi alla schermata Home).
I dati sono sincronizzati con Firebase (progetto casa-rosa): si entra con email e password.
